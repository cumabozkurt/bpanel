The free, open-source hosting control panel with a cPanel/WHM feel.

BOZKURT PANEL (BPANEL) gives your customers a familiar cPanel-style panel on port 2083 and you a WHM-style admin on 2087 — on Ubuntu 24.04 LTS and AlmaLinux 9, built only from free software.

Everything a shared-hosting server needs

96 cPanel/WHM tools are wired up — about 82 % of the cPanel/WHM feature list. Anything that needs software the server lacks answers not_installed with a reason instead of pretending to work.

✉Email

Mailboxes, forwarders, catch-all, Roundcube webmail, SPF/DKIM/DMARC, autoresponders, Sieve filters, Rspamd spam filters, delivery tracking and mlmmj mailing lists.

🗂Files & web

File manager with editor, disk usage, FTP/SFTP, directory privacy, hotlink protection, error pages, MIME types, IP blocker and Git version control with deploy.

🛢Databases

MariaDB with wizard, phpMyAdmin single sign-on, remote MySQL hosts, PostgreSQL databases and users, and a live process list.

🌐Domains & DNS

Addon, sub and alias domains, redirects, PowerDNS zone editor, DNSSEC, BIND import/export, zone history with revert, Dynamic DNS and DNS clustering.

⚙Software

MultiPHP 8.1–8.5 with INI editor, App Installer (WordPress, Joomla, Drupal, Nextcloud), WordPress Toolkit, Node.js/Python apps, cron and a browser terminal.

🧭WHM-style admin

Accounts, packages, resellers with privileges, services, SQL settings, bandwidth, update preferences, cPanel cpmove Transfer Tool, plugins and API tokens.

🛡BPanel Shield

Real-time malware scanning with ClamAV, YARA and heuristics, a safe upload pipeline, encrypted quarantine and restore.

🔥Network security

nftables firewall with lockout guard and confirm-or-rollback, fail2ban / CrowdSec, per-domain ModSecurity with the OWASP Core Rule Set.

📦Isolation

CloudLinux-style limits for free: per-account cgroup v2 slices (CPU, RAM, IO, tasks), a bubblewrap cage for shell and cron, hardened PHP-FPM pools.

💾Backups

restic backups to local disk, SFTP or S3-compatible storage, retention, scheduled jobs and automatic restore verification.

📈Monitoring

OS health, SMART, time sync, Prometheus /metrics, alerts to e-mail, Telegram, Slack or Discord, incidents and file-integrity monitoring.

🔗Multi-server & API

Remote nodes over mTLS with a built-in CA, RBAC with 2FA and step-up auth, HMAC-signed webhooks and an OpenAPI 3.1 description of every route.

Install

On a fresh Ubuntu 24.04 LTS or AlmaLinux 9 server (x86_64 or aarch64, 2 GB RAM, 20 GB disk), as root.

v1.0.0 archives are not signed yet and BPANEL has not yet been run on a real Ubuntu 24.04 / AlmaLinux 9 server with systemd. Verify the SHA-256 and use a disposable VPS first.
# 1. download v1.0.0 and check it (A=arm64 on ARM servers)
V=1.0.0; A=amd64
curl -fLO https://github.com/cumabozkurt/bpanel/releases/download/v$V/bpanel-$V-linux-$A.tar.gz
curl -fLO https://github.com/cumabozkurt/bpanel/releases/download/v$V/bpanel-$V-linux-$A.tar.gz.sha256
sha256sum -c bpanel-$V-linux-$A.tar.gz.sha256

# 2. unpack and install
tar -xzf bpanel-$V-linux-$A.tar.gz && cd bpanel-$V-linux-$A
sudo BPANEL_ALLOW_UNSIGNED=1 ./install.sh \
  --hostname panel.example.com --email admin@example.com \
  --profile full --lang en --yes

The installer is staged and resumable, waits for cloud-init and apt locks, and prints the panel URLs plus a one-time admin login link at the end.

Build from source

Go 1.27+, Node 20+ and pnpm. The built UI is committed, so go build ./... works on a fresh clone.

git clone https://github.com/cumabozkurt/bpanel.git
cd bpanel
make web embed      # build the SvelteKit UI
make vet test       # go vet + go test
make build          # binaries in bin/
make dev            # mock agent on :2083 / :2087, no root
make release        # signed tarballs (needs your key)

Upgrade & uninstall

sudo bpanel-installer upgrade
sudo bpanel-installer uninstall          # sites keep running
sudo bpanel-installer uninstall --purge  # also panel DB + secrets

Secure by design

The web-facing API never runs as root. Every privileged change goes through a small root agent that only knows a fixed list of typed actions — no shell, no "run command".

bpanel-api

Go HTTP API + embedded SvelteKit UI. Runs as the unprivileged bpanel user under systemd hardening. SQLite state, RBAC, CSRF, argon2id, TOTP 2FA.

bpanel-agent

Root helper on /run/bpanel/agent.sock, accepts only the API's uid (SO_PEERCRED). Strictly decoded parameters, argv-only execution, tenant ownership checks.

bpanel-installer

Staged, resumable installer, upgrader and uninstaller that leaves sites running. Renders every config for review; SELinux and nftables aware.

bpanel CLI

version, login-link, admin, selftest, doctor, openapi — server-side admin tasks.

Stack it configures: Nginx (+ optional Apache), PHP-FPM, MariaDB, PowerDNS, Postfix + Dovecot + Rspamd, Roundcube, phpMyAdmin, Pure-FTPd, Let's Encrypt (lego), restic and nftables. Read architecture.md and security.md.
