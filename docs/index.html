The free, open-source hosting control panel with a cPanel/WHM feel.

Ücretsiz ve açık kaynaklı, cPanel/WHM hissiyle hosting kontrol paneli.

BOZKURT PANEL (BPANEL) gives your customers a familiar cPanel-style panel on port 2083 and you a WHM-style admin on 2087 — on Ubuntu 24.04 LTS and AlmaLinux 9, built only from free software.

BOZKURT PANEL (BPANEL), müşterilerinize 2083 portunda tanıdık bir cPanel tarzı panel, size de 2087 portunda WHM tarzı bir yönetim paneli sunar — Ubuntu 24.04 LTS ve AlmaLinux 9 üzerinde, yalnızca özgür yazılımla.

Everything a shared-hosting server needs

Paylaşımlı hosting sunucusunun ihtiyacı olan her şey

118 tools cover 100 % of the cPanel/WHM feature list. Anything that needs software the server lacks answers not_installed with a reason instead of pretending to work.

118 araç, cPanel/WHM özellik listesinin %100'ünü karşılar. Sunucuda eksik yazılım gerektiren bir işlem, çalışıyormuş gibi davranmak yerine nedeniyle birlikte not_installed yanıtı verir.

Posta kutuları, yönlendiriciler, catch-all, Roundcube web posta, SPF/DKIM/DMARC, otomatik yanıtlayıcılar, Sieve filtreleri, Rspamd spam filtreleri, e-posta yönlendirme (routing), BoxTrapper, GnuPG şifreleme, teslimat takibi ve mlmmj e-posta listeleri.

Install

Kurulum

On a fresh Ubuntu 24.04 LTS or AlmaLinux 9 server (x86_64 or aarch64, 2 GB RAM, 20 GB disk), as root.

Temiz bir Ubuntu 24.04 LTS veya AlmaLinux 9 sunucuda (x86_64 ya da aarch64, 2 GB RAM, 20 GB disk), root olarak.

v1.1.0 archives are not signed (no release key yet) — verify the SHA-256. v1.1.0 was tested end to end in an Ubuntu 24.04 container with systemd, but not yet on a real VPS or on AlmaLinux 9. Try it on a disposable server first.
v1.1.0 arşivleri imzasızdır (henüz sürüm anahtarı yok) — SHA-256 değerini doğrulayın. v1.1.0, systemd'li bir Ubuntu 24.04 konteynerinde uçtan uca test edildi; ancak henüz gerçek bir VPS'te veya AlmaLinux 9'da denenmedi. Önce silinebilir bir sunucuda deneyin.
# 1. download v1.1.0 and check it (A=arm64 on ARM servers)
V=1.1.0; A=amd64
curl -fLO https://github.com/cumabozkurt/bpanel/releases/download/v$V/bpanel-$V-linux-$A.tar.gz
curl -fLO https://github.com/cumabozkurt/bpanel/releases/download/v$V/bpanel-$V-linux-$A.tar.gz.sha256
sha256sum -c bpanel-$V-linux-$A.tar.gz.sha256

# 2. unpack and install
tar -xzf bpanel-$V-linux-$A.tar.gz && cd bpanel-$V-linux-$A
sudo BPANEL_ALLOW_UNSIGNED=1 ./install.sh \
  --hostname panel.example.com --email admin@example.com \
  --profile full --lang en --yes

Build from source

Kaynaktan derleme

Go 1.27+, Node 20+ and pnpm. The built UI is committed, so go build ./... works on a fresh clone.

Go 1.27+, Node 20+ ve pnpm. Derlenmiş arayüz depoda olduğundan temiz bir klonda go build ./... çalışır.

git clone https://github.com/cumabozkurt/bpanel.git
cd bpanel
make web embed      # SvelteKit UI
make vet test       # go vet + go test
make build          # bin/
make dev            # mock agent :2083 / :2087, no root
make release        # signed tarballs (your key)

sudo bpanel-installer uninstall          # sites keep running
sudo bpanel-installer uninstall --purge  # also panel DB + secrets
sudo bpanel-installer upgrade            # v1.0.0 → v1.1.0 yerinde
sudo bpanel-installer uninstall          # siteler çalışmaya devam eder
sudo bpanel-installer uninstall --purge  # panel DB + gizli anahtarlar da silinir

Secure by design

Tasarımdan güvenli

The web-facing API never runs as root. Every privileged change goes through a small root agent that only knows a fixed list of typed actions — no shell, no "run command".

Web'e açık API asla root olarak çalışmaz. Her ayrıcalıklı değişiklik, yalnızca sabit bir tipli işlem listesini bilen küçük bir root ajanından geçer — kabuk yok, "komut çalıştır" yok.

bpanel-api

Go HTTP API + embedded SvelteKit UI. Runs as the unprivileged bpanel user under systemd hardening. SQLite state, RBAC, CSRF, argon2id, TOTP 2FA.

Go HTTP API + gömülü SvelteKit arayüzü. systemd sıkılaştırmasıyla ayrıcalıksız bpanel kullanıcısı olarak çalışır. SQLite, RBAC, CSRF, argon2id, TOTP 2FA.

bpanel-agent

Root helper on /run/bpanel/agent.sock, accepts only the API's uid (SO_PEERCRED). Strictly decoded parameters, argv-only execution, tenant ownership checks.

/run/bpanel/agent.sock üzerindeki root yardımcı; yalnızca API'nin uid'sini kabul eder (SO_PEERCRED). Katı parametre çözümleme, yalnızca argv ile çalıştırma, sahiplik denetimi.

bpanel-installer

Staged, resumable installer, upgrader and uninstaller that leaves sites running. Renders every config for review; SELinux and nftables aware.

Aşamalı, devam ettirilebilir kurulum, yükseltme ve siteleri çalışır bırakan kaldırma aracı. Her yapılandırmayı inceleme için üretir; SELinux ve nftables uyumlu.

bpanel CLI

version, login-link, admin, selftest, doctor, openapi — server-side admin tasks.

version, login-link, admin, selftest, doctor, openapi — sunucu tarafı yönetim görevleri.

Stack it configures: Nginx (+ optional Apache), PHP-FPM, MariaDB, PostgreSQL, PowerDNS, Postfix + Dovecot + Rspamd, Roundcube, phpMyAdmin, Pure-FTPd, Radicale, Let's Encrypt (lego), restic and nftables. Read architecture.md and security.md.

Yapılandırdığı yazılımlar: Nginx (+ isteğe bağlı Apache), PHP-FPM, MariaDB, PostgreSQL, PowerDNS, Postfix + Dovecot + Rspamd, Roundcube, phpMyAdmin, Pure-FTPd, Radicale, Let's Encrypt (lego), restic ve nftables. Ayrıntılar: architecture.md ve security.md.
