# BOZKURT PANEL v1.2.1 — 2026-10-11

**Signed releases and a one-command install.** Same panel as [v1.2.0](v1.2.0.md) (16 one-click apps,
97 / 97 cPanel/WHM rows, EN/TR UI); this release adds the release signing key, so `install.sh` can
download and *verify* the panel on its own.

- Repository: <https://github.com/cumabozkurt/bpanel>
- Website (EN/TR, follows the browser language): <https://cumabozkurt.github.io/bpanel/>
- Changelog: [`CHANGELOG.md`](../../CHANGELOG.md) · Upgrade: [`docs/upgrade.md`](../upgrade.md)

## Install

```bash
curl -fsSL https://github.com/cumabozkurt/bpanel/releases/latest/download/install.sh | sudo bash -s -- \
  --hostname panel.example.com --email admin@example.com --profile full --lang en --yes
```

Upgrade an existing v1.x server: `curl -fsSL https://github.com/cumabozkurt/bpanel/releases/latest/download/install.sh | sudo bash -s -- upgrade`.
