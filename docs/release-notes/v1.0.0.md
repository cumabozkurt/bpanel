# BOZKURT PANEL v1.0.0 — 2026-10-10

**First public open-source release.** Free (Apache-2.0) web hosting control panel with a
cPanel/WHM-style layout and the same ports (2083 user, 2087 admin, 2096 webmail) for
**Ubuntu 24.04 LTS** and **AlmaLinux 9**. 100 % free software: no paid component, licence or API.

- Repository: <https://github.com/cumabozkurt/bpanel>
- Website: <https://cumabozkurt.github.io/bpanel/>
- Full changelog: [`CHANGELOG.md`](../../CHANGELOG.md#v100--2026-10-10-first-public-open-source-release)

> **Please read before installing.** v1.0.0 has passed every automated test listed below, but it
> has **not yet been run on a real Ubuntu 24.04 / AlmaLinux 9 server with systemd as PID 1**, and
> the archives are **not signed** (no release key yet). Start with a disposable VPS.

## What is in 1.0.0

The complete v0.4 feature set — 96 cPanel/WHM tools wired, about 82 % of the cPanel/WHM feature
list implemented and about 34 % verified end to end in a container (`docs/feature-matrix.md`):

- **Email:** accounts, forwarders, catch-all, Roundcube webmail, SPF/DKIM/DMARC, autoresponders,
  Sieve filters, Rspamd spam filters, delivery tracking, mailing lists (mlmmj).
- **Files & web:** file manager, disk usage, FTP/SFTP, restic backups and restore (local/SFTP/S3,
  restore verification), directory privacy, hotlink protection, error pages, MIME types, IP blocker,
  Git version control.
- **Databases:** MariaDB + wizard, phpMyAdmin SSO, remote MySQL, PostgreSQL, process list.
- **Domains & DNS:** addon/sub/alias domains, redirects, PowerDNS zone editor, DNSSEC, zone
  import/export and history, Dynamic DNS, DNS cluster.
- **Software:** MultiPHP 8.1–8.5 + INI editor, App Installer (WordPress, Joomla, Drupal, Nextcloud),
  WordPress Toolkit, Node.js/Python Application Manager, cron, browser terminal, Track DNS.
- **WHM:** accounts, packages, resellers with privileges, services, update preferences, SQL
  settings, bandwidth, Transfer Tool (cPanel `cpmove` import), backups, plugins, API tokens, OpenAPI 3.1.
- **Security platform:** RBAC, 2FA with recovery codes, step-up auth, encrypted secrets (optional
  OpenBao), BPanel Shield (ClamAV/YARA/heuristics, quarantine), nftables firewall with
  confirm-or-rollback, fail2ban/CrowdSec, ModSecurity + OWASP CRS, cgroup v2 isolation and bwrap
  cage, multi-server over mTLS, monitoring/alerts/FIM with Prometheus metrics, signed webhooks.

## Changes since v0.4.0

- **Fixed** `xfer.CleanName` (Transfer Tool archive reader): names such as `./\x` / `./C:x` that
  only look absolute after cleaning are now refused (found by `FuzzCleanName`; regression corpus added).
- **Fixed** the `--node` join instructions: `/msrv/join` is on port **2083**, not 8443.
- **Fixed** `bpanel-installer render --out DIR` when `DIR` does not exist yet.
- **Fixed** data races in two API tests (`go test -race ./...` is green again).
- **Fixed** the root-mode `install.sh` end-to-end test expectation (binaries run from `/usr/local/lib/bpanel`).
- **Fixed** `make dev` secret store (key kept in `--dev-dir`, no `/etc/bpanel` needed).
- **Fixed** `.gitignore` hiding `internal/webui/dist` (a fresh clone now builds).
- **Changed** version 1.0.0 everywhere (installer default was still 0.3.0; OpenAPI said 0.3.0); gofmt.
- **Added** GitHub Pages website, v1 screenshots, CONTRIBUTING, SECURITY policy, CI workflow.

No database migration and no new package: upgrading from 0.4.0 only swaps binaries and re-applies
the configuration (`docs/upgrade.md`).

## Assets

| File | What |
|---|---|
| `bpanel-1.0.0-linux-amd64.tar.gz` / `-arm64.tar.gz` | static binaries (`bpanel`, `bpanel-api`, `bpanel-agent`, `bpanel-installer`), `install.sh`, `SHA256SUMS`, LICENSE, NOTICE, README |
| `*.tar.gz.sha256` | SHA-256 of each archive |

**The archives are unsigned.** Verify the SHA-256, unpack, then
`sudo BPANEL_ALLOW_UNSIGNED=1 ./install.sh --hostname panel.example.com --email admin@example.com --profile full --yes`.
Or build and sign your own release: `make release-keygen && make release`.

## Known limitations

- Not yet run on a real Ubuntu 24.04 / AlmaLinux 9 VM (systemd, SELinux, `ssh.socket`,
  systemd-resolved, nftables, AutoSSL against Let's Encrypt staging).
- No release signing key yet; `curl | bash` from `get.bozkurtpanel.com` is not available.
- Deferred items CODE-21/23/25/26, per-tenant PHP-FPM cgroups, certificate reload fan-out for
  Postfix/Dovecot/Pure-FTPd — see "Known limitations" in the README.
